## Release assessment
G0 (reproducible local analytical tools): holds on this environment (WP01 rerun).
G1 (complete coding-agent workflow) is **established on this host** in the blueprint's sense: a
real provider, an isolated worktree, bounded tools inside the tested Linux-namespace backend,
independent tests, durable resume and artifact export worked together on seeded tasks
(`evidence/live/summary.json`, `evidence/wp11/`, `evidence/doctor_linux_namespace_selftest.json`,
`evidence/test_results.txt`), and the release route (restore bundle, doctor, identity manifest,
smoke workflow) was executed (`evidence/wp12/`). The claim is scoped: one host, one provider,
synthetic tasks. The **advantage gate is not passed**: under three frozen protocols Gabriel's
verified success never exceeded the simple verification loop's (paired means -0.17, -0.04,
0.00) and its cost was higher (one planner request per plan version; about 2.5 s of
observation, journal and review per task at equal model cost for the reference-plan variant).
After the last defect fix every system solves the whole corpus on its first request, so the
distribution no longer discriminates; the next protocol needs a harder frozen distribution. The
root license is Apache-2.0 (`LICENSE`), so the release gate's license review is closed
(`docs/RELEASE_G1.md`).
G2 (general workspace agent) is **established on this host in the blueprint's scoped sense**:
one frozen owner/scheduler/policy build ran repository repair, source-grounded document
amendment and numerical transformation with registered domain observers, independent oracles,
invalid and out-of-scope controls and recorded replay (`docs/RELEASE_G2.md`,
`evidence/wp10/at23/`). The claim is limited to the three fixture task families; the analytical
adapters are the standard-library worker and, since ADR-18, the native PSE graph engine built
from the locked sources and run as a contained worker with independent references
(`evidence/pse/`), deterministic by construction since ADR-19, and since ADR-20 the memory's
associative layer (executed under protocol 6b, `evidence/wp15/`). The
advantage gate was also executed on these two families (protocol 5, ADR-16, `evidence/wp14/`):
verification removed the provider-only baseline's false completions on the conflict family, but
so did the simple verification loop at no higher cost, and the declared ablations of
provenance-aware retrieval and the revision rule stayed below the declared minimum relevant
effect for gpt-4.1-mini, so the gate is **not passed** there either.
G3 (evaluated adaptive policies) is **established in the blueprint's scoped sense** since
protocol 8 (`docs/RELEASE_G3.md`, ADR-22, `evidence/wp15/`). Protocol 4 (`evidence/wp13/`) had
found no failed verification in 126 runs on the hard tier, so no readout could be trained then,
and the episodic-retrieval ablation failed its criterion. On the association distribution, with
the document pack's declared progress channels, a logistic readout trained on 48 retained
decisions of the system's own runs met the declared held-out criterion on two unseen topics
(equal verified success, 2836 against 5425 mean tokens, no false completion), its decision loss
was 0.045 against the rule's 6.91 on the held-out decisions, and the memory's promotion rule
admitted it; it ships pinned as the document pack's default routing policy with its provenance.
The claim is bounded: the readout learned one legible fact (stop when the unmet claim expects a
source the retrieval did not carry), it can only stop a repair earlier than the rule, it stopped
one recoverable repair on a seen task, the held-out decisions were of one class, and the
evidence is one pack and one constructed distribution under two providers of one vendor
(protocol 9 repeated the tier with gpt-5-mini: the readout, weights fixed, again met the
held-out criterion and stopped every hopeless repair at the first decision).

## Known limitations and open items
- `trusted_local` mode has no containment: a daemonized descendant survives (the witness
  reports `descendants_cleaned: false`), the host environment is scrubbed but the filesystem
  and network are open. It exists only for trusted repositories and is opt-in.
- Scripted provider cursors live in process memory; after a restart the script replays from
  its first response per step key (deterministic, documented).
- The planner prompt embeds a reference plan; a real model reproduces it in practice (103 of
  the 104 planner responses retained in runs 1 and 2 have the reference plan's node, dependency
  and check structure), which is why `gabriel_reference_plan` exists. Plan validation (unknown capability, unknown check, omitted
  mandatory check, cycle, limits) is enforced by the owner independently of the model.
- The capability catalog is fingerprinted from the loaded implementation source. Changing a tool
  module makes existing workspaces refuse to open until `gabriel migrate` moves them explicitly
  (backup, equivalence replay, recorded epoch; ADR-17). Workspaces created before catalog
  records existed migrate only when the running code reproduces their journal as is; the
  retained evidence workspaces of G2 and protocol 5 were refused on that rule (verifier
  implementations changed) and stay readable with the code identity their release manifest
  records.
- Invalid or truncated provider output is retained as a failed attempt and retried within the
  node's attempt limit with the diagnostic in the next prompt.
- The ADR-10 hold operation and ADR-11 planner bootstrap intent extend the proposed contract;
  the vendored specification files are unchanged apart from the two additive enum values.
- Memory retrieval is lexical, re-ranked by the native engine's walk over verified co-citations
  under the document pack's default associative view (ADR-20, ADR-21), projected onto the
  retrieval's own candidates (ADR-23: a withdrawn or unauthorized source leaves the history, a
  claim contributes only while two of its keys remain, there is no erosion by time); no
  retrieval policy is trained. The one promoted routing policy is the document pack's readout of ADR-22 (one
  provider, one constructed distribution, 48 training decisions); every other pack runs the
  rule-based policy. The native PSE executables are built from source per host (cargo); without
  them native graph operations are refused at proposal time and the associative view records
  `unavailable` and stays lexical.
- Document extraction supports UTF-8 text only; other formats are observed as `unsupported`
  and can never be cited.
