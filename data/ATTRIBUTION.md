# External measurement datasets

## Continuous-prefix extension (25 September 2026)

The additional original train/test files are distributed by **TSML Archive
Maintainers** under **CC BY 4.0**. All four file MD5 values match the corresponding
Zenodo deposit. Download URLs, byte counts, SHA-256 and MD5 values, and license
identifiers are recorded in `prefix_provenance.json`; complete retrieved deposit
metadata are saved alongside it.

- **NATOPS**: https://doi.org/10.5281/zenodo.11206248.
  Archive description and underlying competition attribution:
  https://www.timeseriesclassification.com/description.php?Dataset=NATOPS.
  Original UEA split: 180 training and 180 test records, 51 events, 24 channels,
  six gesture classes. The description links to the AALTD 2016 competition.
- **Epilepsy**: https://doi.org/10.5281/zenodo.11206204.
  Archive donor: Jose Ramon Villar, UEA. Description:
  https://www.timeseriesclassification.com/description.php?Dataset=Epilepsy.
  Original split: 137 training and 138 test records, three channels, four classes.
  **The unchanged files and their headers contain 206 events; the web table
  instead lists 207. All computations use the file contents.** Measurements
  concern healthy participants performing activities including seizure mimicking,
  not clinical EEG or a diagnostic validation. The description reports three
  participants per split, with participant identifiers removed.

No raw record, class label or split was changed. Derived normalized arrays use
training-only statistics. Newly imposed masks, models and query paths are project
outputs. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.
No endorsement by the original collectors or archive maintainers is implied.

## Earlier external study (24 September 2026)

The RacketSports and BasicMotions `.ts` files are unchanged copies of the original UEA archive train/test
splits. They were downloaded from the Time Series Classification archive on
24 September 2026. All four MD5 values match the corresponding TSML-maintained
Zenodo deposit. File sizes, SHA-256 values, download locations and verified
deposit checksums are in `provenance.json`.

- **RacketSports**: Phillip Perks, University of East Anglia (undergraduate
  collection, 2017/18), distributed by **TSML Archive Maintainers**.
  Dataset deposit: https://doi.org/10.5281/zenodo.11206263 (metadata date October 2018).
  Description: https://timeseriesclassification.com/description.php?Dataset=RacketSports
- **BasicMotions**: Jack Clements, University of East Anglia (collection, 2016),
  distributed by **TSML Archive Maintainers**.
  Dataset deposit: https://doi.org/10.5281/zenodo.11206179 (metadata date October 2018).
  Description: https://timeseriesclassification.com/description.php?Dataset=BasicMotions

Both TSML-maintained deposits declare **Creative Commons Attribution 4.0
International**: https://creativecommons.org/licenses/by/4.0/.
This attribution applies to the external data, not a newly assigned license for
the accompanying research code or manuscript. Original data-file headers are
retained. No original record or split has been changed in `data/`.

The numerical pipeline creates normalized arrays using training-only channel
statistics and a tanh transform; these derived arrays are identified in the
model archives. Synthetic missing masks and retrieval paths are new experiment
outputs. The input observations and external class labels were not generated by
this project. No endorsement by the collectors or archive maintainers is implied.

Archive reference: Anthony Bagnall, Hoang Anh Dau, Jason Lines, Michael Flynn,
James Large, Aaron Bostrom, Paul Southam and Eamonn Keogh, *The UEA Multivariate
Time Series Classification Archive, 2018*, arXiv:1811.00075v1.
